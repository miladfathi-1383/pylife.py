# Pylife Manager 🚀

Pylife Manager is a simple CLI project that I built while learning Python.

It includes basic people and task management, JSON data storage, input validation, error handling, logging, and some object-oriented programming concepts.

I am really happy to have finished this project. It is a very simple project, but for me, it is an important starting point. It gave me the chance to use the things I learned in Python in one complete project and prepare myself to move on to many other topics.

This project was developed with the help of AI as a learning assignment and assistance. I used AI for guidance, understanding concepts, troubleshooting, and solving problems while writing, testing, and understanding the code myself.

This is just the beginning. 🚀
